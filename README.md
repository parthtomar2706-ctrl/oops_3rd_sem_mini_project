# Vehicle Rental Management System 🚗🏍️

A console-based **Vehicle Rental Management System** developed in C++ as part of an Object-Oriented Programming (OOP) academic mini project. The application allows users to manage a fleet of vehicles (Cars and Bikes), track availability, calculate rental bills, and persist data using file handling.

## ✨ Features
* **Object-Oriented Design:** Utilizes a base `Vehicle` class with derived `Car` and `Bike` subclasses.
* **Fleet Management:** View available vehicles and check rental statuses instantly.
* **Rental & Billing Calculation:** Automatically computes total rental charges based on user-defined rental duration.
* **Return System:** Seamlessly process vehicle returns and update inventory availability.
* **Data Persistence:** Saves and loads vehicle inventory states using text files (`data.txt`).

## 🛠️ OOP Concepts Demonstrated
* Classes and Objects
* Inheritance & Polymorphism (`virtual` functions)
* Encapsulation
* Standard Template Library (STL `std::vector`)
* File Handling (`std::ifstream` and `std::ofstream`)
